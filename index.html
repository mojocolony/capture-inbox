Dropbox settings

Your capture files stay in Dropbox. The site is public code, but capture contents are accessible only after Dropbox authorization.

Never enter an app secret or access token here.

Use /Apps/Capture Inbox for Full Dropbox access to your existing archive. For a restricted App Folder integration, use its accessible folder path (often blank for its root), and ensure the Shortcut writes into that same folder.

REDIRECT URI TO REGISTER IN DROPBOX
Privacy: This browser-only prototype keeps OAuth tokens in the current tab's session storage, not in published files or permanent browser storage. Closing the tab requires reconnecting. Dropbox permissions determine which files the app can access.
How to set up Dropbox OAuth
  1. Visit Dropbox App Console and create a Scoped access application.
  2. Select either Full Dropbox (works with your existing archive path, but grants broader access) or App Folder (restricted, but requires locating/moving captures into the app's folder).
  3. Enable files.metadata.read, files.content.read, and files.content.write under Permissions, then submit.
  4. Add the redirect URI displayed above under OAuth 2 → Redirect URIs. Enter the app key here, not the app secret.
  5. Connect and approve access. Review status is saved as _capture_inbox_state.json alongside your captures.
